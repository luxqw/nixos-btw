# Home workout

`plan.json` is an openGym plan file (Plan → Share your plan → Import).
`wizards/opengym.sh` installs the app and imports it.

No equipment, 2 m² of floor, three full-body sessions a week, about 30
minutes each: **Mon A · Wed B · Fri A**. Every session opens with a minute
of jumping jacks and the world's greatest stretch.

| | A | B |
|---|---|---|
| Legs | squat 3 × 12–25 | split squat 3 × 8–15/side |
| Push + pull, superset | push-up 3 × 6–15 + prone Y raise 3 × 10–20 | pike push-up 3 × 5–12 + superman 3 × 10–20 |
| Hinge | single leg bridge 3 × 8–15/side | single leg deadlift 3 × 8–15/side |
| Core | front plank 3 × 30 s, +5 s | side plank 3 × 20 s/side, +5 s |

Rest is 60 s for legs, 90 s after each superset round, and 30 to 45 s for the rest.

**Progression.** openGym's bodyweight rule: after a session with every set
clean, one more rep (two on per-side moves) until the top of the range, then a
set is added and the reps drop back to the bottom. Once an exercise reaches 4
sets at the top, swap it for the harder variation instead, to keep a session
near 30 minutes:

- squat → split squat → Bulgarian split squat on a chair (3743)
- knee push-up (1182) → push-up → pike push-up
- single leg bridge → glute bridge one leg on bench (2473), the sofa as bench

A missed rep repeats the same target next time.
