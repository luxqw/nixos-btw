# nvim

[LazyVim](https://lazyvim.org). Плагины ставит lazy.nvim, версии
зафиксированы в `lazy-lock.json`. LSP, форматтеры, линтеры и treesitter-парсеры ставит Nix
(`home.nix`), поэтому Mason выключен. Наши правки — в `lua/plugins/`.

## С чего начать

1. Если vim в новинку — `vimtutor` в шелле (30 минут).
2. Нажми `Space` и подожди: which-key покажет всё, что дальше.
3. `Space s k` ищет по всем биндам, `Space s h` — по `:help`.
4. hardtime.nvim подсказывает, когда жмёшь `jjjj` вместо `5j`. `:Hardtime report`.

## Шпаргалка

`<leader>` = `Space`. ★ — то, чем пользуешься каждый день.

### Файлы и поиск

| Клавиши | Что делает |
|---|---|
| ★ `Space Space` | найти файл в проекте |
| ★ `Space /` | grep по проекту |
| ★ `Space ,` | открытые буферы |
| `Space f r` | недавние файлы |
| ★ `Space e` | дерево файлов |
| `Space s s` | символы в файле |

### Код (LSP)

| Клавиши | Что делает |
|---|---|
| ★ `gd` | к определению |
| ★ `gr` | где используется |
| ★ `K` | документация под курсором |
| ★ `Space c a` | code action |
| `Space c r` | переименовать символ |
| `Space c f` | отформатировать (и так форматирует при сохранении) |
| ★ `]d` / `[d` | следующая / предыдущая ошибка |
| `Space x x` | все ошибки списком |
| `gcc` / `gc` | закомментировать строку / выделение |

### Окна и буферы

| Клавиши | Что делает |
|---|---|
| ★ `Shift+h` / `Shift+l` | предыдущий / следующий буфер |
| `Space b d` | закрыть буфер |
| `Ctrl+h j k l` | между окнами |
| `Space -` / `Space \|` | сплит вниз / вправо |
| `Ctrl+/` | терминал |
| `Space q q` | выйти из всего |

### Движение и правка

| Клавиши | Что делает |
|---|---|
| ★ `s` + 2 буквы | прыжок в любое место экрана (flash) |
| `w` / `b` / `e` | по словам |
| `{` / `}` | по абзацам |
| `ciw` / `ci"` / `cit` | заменить слово / в кавычках / в теге |
| `Alt+j` / `Alt+k` | переместить строку вниз / вверх |
| `u` / `Ctrl+r` | undo / redo |

### Git

| Клавиши | Что делает |
|---|---|
| ★ `Space g g` | lazygit (`e` на файле открывает его в этом nvim) |
| `]h` / `[h` | следующий / предыдущий hunk |
| `Space g b` | blame строки |

## Как устроено

- `lua/config/lazy.lua` — LazyVim и языки: go, json, markdown, nix, yaml.
- `lua/plugins/nix.lua` — стык с Nix: Mason выключен, nvim-treesitter из Nix, `nixd` и
  `alejandra` вместо `nil_ls` и `nixfmt`.
- `lua/plugins/base16.lua` — цвета из обоев (noctalia пишет `lua/matugen.lua`).
- Новый язык: `import` экстры в `lazy.lua` + сервер, форматтер и грамматика в `home.nix`.
- `:Lazy update` двигает версии и меняет `lazy-lock.json` — его коммитить, как `flake.lock`.
